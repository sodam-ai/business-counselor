# Lean Canvas 스킬

## 목적

사업 아이디어를 **Lean Canvas 9블록**으로 구조화하여 비즈니스 모델 전체를 한눈에 파악한다.

## 9블록 정의 및 작성 순서

| 블록 | 설명 | 작성 포인트 |
|------|------|-----------|
| 1. Problem | 해결하려는 핵심 문제 1~3개 | 가장 고통스러운 문제 우선 |
| 2. Customer Segments | 타겟 고객 (초기 얼리어답터 포함) | B2C/B2B 명확히 구분 |
| 3. Unique Value Proposition | 차별화된 가치 한 문장 | "X를 위한 Y" 형식 |
| 4. Solution | 문제 해결 방법 (최소 기능) | 각 문제에 1:1 대응 |
| 5. Channels | 고객 도달 경로 | 초기: 가장 저비용 경로 |
| 6. Revenue Streams | 수익 모델 (구독/거래/광고 등) | 단가·빈도·볼륨 추정 |
| 7. Cost Structure | 주요 비용 항목 | 고정비 vs 변동비 구분 |
| 8. Key Metrics | 핵심 지표 1~3개 | 검증 가능한 측정값 |
| 9. Unfair Advantage | 모방 불가 경쟁 우위 | 진입 장벽·독점 자산 |

## 작성 규칙

- **사용자 프로필 맥락 반영**: 자본·시간·역량을 Cost Structure와 Solution에 반영
- **출처 없는 수치**: "추정" 명시 필수
- **Phase 1 축소 허용**: 각 블록 2~3줄
- **9블록 작성 순서**: Problem → Customer Segments → UVP → Solution → Channels → Revenue → Cost → Metrics → Unfair Advantage
