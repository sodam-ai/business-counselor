# Pre-mortem 스킬 (Phase 2 — 5개)

> Phase 1의 3개 버전은 `agents/bc-idea-evaluator.md` §4에 인라인으로 구현되어 있음(정식 스킬 파일 없이 본문 내장). Phase 2부터는 이 스킬 파일을 참조해 5개로 확장.

## 목적

프로젝트가 **실패했다고 가정**하고, 가장 가능성 높은 실패 원인 5가지를 선제적으로 도출한다. Phase 1(3개)에서 확장.

## 시나리오 생성 규칙

- 각 시나리오 = 원인(cause) + 확률(prob: 상/중/하) + 완화책(mitigation) 3요소 — `02_DATA_MODEL.md`의 `pre_mortem_failures: [{cause, prob, mitigation}]` 구조와 정합
- 사용자 프로필 약점(자본·시간·역량 갭) 직접 반영
- §5 적대 토론 Bear 논거와 중복 최소화 (Pre-mortem은 실행 실패 중심, Bear는 시장 실패 중심)
- 5개 카테고리 권장 분포(강제 아님, 가이드): 실행력(시간·역량 부족) 1~2개 / 시장(경쟁·타이밍) 1~2개 / 자본(소진·자금난) 1개 / 팀·역량 1개 / 외부 변수(규제·기술변화) 1개

## 출력 형식 (§4 섹션)

```
## § 4. Pre-mortem 시나리오 5개

1. **[실패 원인명]** (확률: 상/중/하): 구체적 설명 1~2문장 → 완화책: 1줄
2. **[실패 원인명]** (확률: 상/중/하): 구체적 설명 1~2문장 → 완화책: 1줄
3. **[실패 원인명]** (확률: 상/중/하): 구체적 설명 1~2문장 → 완화책: 1줄
4. **[실패 원인명]** (확률: 상/중/하): 구체적 설명 1~2문장 → 완화책: 1줄
5. **[실패 원인명]** (확률: 상/중/하): 구체적 설명 1~2문장 → 완화책: 1줄
```
