# 13명 다관점 평가 스킬 (페르소나 v5 1:1 매칭)

## 목적

사업 아이디어를 **13명 전문가 시점에서 1~5점으로 평가**하고 한 줄 코멘트를 제공한다.
13명은 사용자 페르소나 v5와 1:1 직접 매칭된 전문가들이다.

## 13명 전문가 표

| # | 전문가 (15년+ 경력 기본) | 평가 축 |
|---|------------------------|---------|
| 1 | 시니어 개발자 | 기술 구현 가능성·유지보수 부담·확장성 |
| 2 | 시니어 보안 전문가 | OWASP·데이터 보안·인증 위험·암호화 |
| 3 | 비개발자/왕초보/무경험자 | 진입 장벽·이해 가능성·실수 가능성 |
| 4 | QA/테스트 엔지니어 | 검증·MVP 테스트 비용·엣지 케이스 |
| 5 | DevOps/배포·운영/SRE | 인프라·배포·장애·환경변수 관리 |
| 6 | 데이터/AI 엔지니어 | AI 활용·환각 위험·데이터 윤리·LLM 비용 |
| 7 | 시니어 디자이너 | UI·시각적 매력·색상·레이아웃 |
| 8 | UX 리서처 | 사용성·여정·접근성·첫 5분 경험 |
| 9 | 시니어 PM/PO | MVP·우선순위·로드맵·요구사항 명료성 |
| 10 | C-레벨 경영진/비즈니스 (25년+) | 매출·시장 규모·경쟁사·BM 견고성 |
| 11 | **법무/컴플라이언스 (15년+ 변호사)** | **자본시장법·창업컨설팅업·면책·GDPR·약관** |
| 12 | 비용 최적화/사업 운영 (15년+) | ROI·운영 비용·토큰 비용·가성비 |
| 13 | **전문 투자자 (15년+)** | **사업 성공 가능성·리스크·포지셔닝·백테스트 사고** |

## 평가 규칙

- 각 전문가: **1~5점 + 한 줄 코멘트** (출력 시 한 행, 30자 이내)
- **5점 기준**: 명확한 강점 증거 있을 때만 (보수적·under-promise)
- **1점 기준**: 치명적 결함·회색지대 해당 시
- **합산 평균이 아닌 분포에 가중치** — #11·#13의 강한 부정 신호(1~2점)는 평균 4.0이라도 verdict를 "iterate" 또는 "no-go"로 강제

## 도메인 자동 강조 트리거

| 도메인 키워드 감지 | 활성 전문가 | 처리 |
|-------------------|-----------|------|
| 자본시장법·창업컨설팅·투자자문업·약관·면책·규제·GDPR·audit·금감원·AML | #11 변호사 | 섹션 강조 + 면책 경고 |
| 투자·거래·매매·주식·코인·자동매매·수익·손실·포트폴리오·백테스트·리스크 | #13 투자자 | 섹션 강조 + 리스크 경고 |
| 양쪽 동시 | #11 + #13 | 두 섹션 모두 강조 |
