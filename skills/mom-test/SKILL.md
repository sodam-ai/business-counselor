# Mom Test 스킬

## 목적

두 가지 용도:
1. **인터뷰 단계** (`/business-counselor:start`·`/business-counselor:resume`): 사용자 프로필 수집용 질문 생성
2. **아이디어 평가 단계** (`/business-counselor:evaluate`): "잠재 고객이 실제 돈 낼 증거" 검증 질문 5개 생성

## Mom Test 핵심 원칙

### 좋은 질문 (PASS)
- 과거 행동 기반: "지난 1년 동안 X 문제 해결에 실제로 돈을 쓴 적 있나요?"
- 현재 상황 기반: "지금 이 문제를 어떻게 해결하고 있나요?"
- 구체적 경험: "마지막으로 X를 했을 때 가장 불편했던 점이 뭐였나요?"

### 나쁜 질문 (FAIL — 절대 사용 금지)
- 가설 기반: "만약 X가 있다면 쓸 것 같나요?" ❌
- 미래 의도: "앞으로 이런 서비스를 사용할 의향이 있나요?" ❌
- 칭찬 유도: "이 아이디어 어때요?" ❌

## 인터뷰 단계 — 6카테고리 질문 규칙

| 카테고리 | 질문 목표 | 예시 |
|----------|----------|------|
| 생애사 | 과거 직업·경험·전환점 | "지금까지 가장 오래 한 일이 뭔가요?" |
| 자본 | 가용 투자 가능 자금 | "사업에 투자할 수 있는 초기 자금이 어느 정도인가요?" |
| 시간 | 투입 가능 주당 시간 | "직장 외에 사업에 쓸 수 있는 주당 시간이 몇 시간인가요?" |
| 역량 | 실제 보유 기술·경험 | "직접 만들거나 운영해본 프로젝트가 있나요?" |
| 관심도메인 | 열정 있는 분야 | "최근 1년간 자발적으로 가장 많은 시간을 쓴 분야가 어디인가요?" |
| 리스크성향 | 실패 허용 범위 | "사업 실패 시 감당 가능한 최대 손실 규모가 어느 정도인가요?" |

카테고리당 약 2개 질문. 총 12개. 30~40분 목표.

## 아이디어 평가 단계 — 검증 질문 5개 생성 기준

1. **현재 대안 지출**: "이 문제를 지금 어떻게 해결하고 있고, 한 달에 얼마나 쓰나요?"
2. **불편 강도**: "이 문제 때문에 가장 최근에 구체적으로 손해를 본 사례가 있나요?"
3. **수동 해결 시도**: "이 문제를 직접 해결해보려 한 적 있나요? 어떻게 했나요?"
4. **전환 의지**: "지금 쓰는 해결책을 버리고 새 것을 쓰려면 어떤 조건이 필요한가요?"
5. **준거가격**: "비슷한 도구·서비스에 지금까지 가장 많이 지불해본 금액은?"

## 출력 형식 (§3 섹션)

```
## § 3. Mom Test 검증 질문 5개

1. (현재 대안 지출) ...
2. (불편 강도) ...
3. (수동 해결 시도) ...
4. (전환 의지) ...
5. (준거가격) ...
```

## 토큰 목표

~300 토큰 (5개 질문 × 1~2줄 기준)
